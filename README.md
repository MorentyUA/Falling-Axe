# Falling Axe

2D аркадна ASMR-гра про кирку, що падає крізь нескінченні ряди блоків і ламає руду. Керування мінімальне — уся динаміка тримається на фізиці, вибухах TNT та випадковості. Зроблено на Unity 6 (URP 2D).

## Про гру

- Натискаєш **Enter** — з точки спавну з випадковим кутом і поштовхом вилітає гравець (кирка або куб).
- Гравець падає вниз крізь ряди блоків. Кожен дотик до блоку завдає йому шкоди.
- **Руда** (вугілля, мідь, залізо, золото, лазурит, редстоун, алмаз, смарагд) додає очки до загального рахунку та у свій лічильник.
- **Brainrot-блоки** (Tralalero, Crocodilo, Balerina) рахуються окремо і **тільки** якщо їх зламав сам гравець — вибухи їх не чіпають.
- **TNT** після удару підпалюється, роздувається, вибухає з затримкою і запускає ланцюгову реакцію по сусідніх блоках.
- Якщо гравець завис на місці на 2 секунди — він сам підпалюється, вибухає і респавниться на тому ж місці з новим випадковим виглядом.
- Бічні стіни — це **батути** (`BouncePad`): відкидають гравця назад у поле.
- Зверху за гравцем повзе **стеля-переслідувач**: знищує блоки, що залишились над ним, і відкидає гравця вниз, якщо той піднявся занадто високо.

## Структура скриптів

Усе лежить в `Assets/Scripts/`:

| Скрипт | Що робить |
|---|---|
| `ActivateOnEnter.cs` (`SpawnPlayerOnEnter`) | Старт гри по Enter, блимання підказки, спавн випадкового гравця з пулу (не повторює попередній), партикл і звук спавну |
| `PlayerCube.cs` | Фізика гравця, самопідпал при простої, вибух з радіусом, ланцюгова реакція по TNT, респавн через тимчасовий `RespawnTimer` |
| `DestructibleCube.cs` | Блок з типом руди (`OreType`), кількістю ударів, кольором ушкодження, режимом TNT (затримка, радіус, сила) та нарахуванням очок |
| `RowSpawner.cs` | Генерація рядів блоків під камерою на всю ширину екрана за зваженими шансами (`CubeSpawnData`), очищення блоків, що пішли вгору |
| `ScoreManager.cs` | Сінглтон з загальним рахунком і лічильниками по кожному типу руди, виводить у TextMeshPro |
| `BouncePad.cs` | Батут: відкидає гравця по нормалі, від точки контакту або у заданому напрямку |
| `FollowPlayerDown.cs` | Стеля: слідує за гравцем згори, знищує блоки і відкидає гравця вниз |
| `FollowPlayerVertical.cs` | Об'єкт, що жорстко тримається на висоті гравця (стіни) |
| `CameraFollow.cs` | Камера слідує за гравцем по Y з відступом |

## Префаби

- `Assets/Prefabs/player/` — `player` (куб) та `player pickaxe` (кирка), обидва з тегом `Player`.
- `Assets/Prefabs/minecraft blocks/` — руда, камінь, земля, TNT (100 ударів, вибуховий).
- `Assets/Prefabs/new blocks/` — brainrot-блоки (тег `Brainrot`), `Cube Strong` на 10 ударів, декоративні блоки.
- Корінь `Assets/Prefabs/` — партикли для brainrot, TNT і стін.

## Технології

- Unity **6000.3.8f1**
- Universal Render Pipeline 17.3 (2D Renderer)
- Input System 1.18 (у скриптах поки старий `Input.GetKeyDown`)
- TextMeshPro для UI
- Сцена для білду: `Assets/Scenes/game full hd.unity`, 1920×1080 fullscreen

## Як запустити

1. Відкрити папку проєкту в Unity Hub (версія 6000.3.8f1).
2. Відкрити сцену `Assets/Scenes/game full hd.unity`.
3. Play → натиснути **Enter**.

## Ліцензії ассетів

У проєкті використовуються сторонні демо-паки: **Pixel Skies DEMO** (фони), **Simple FX Kit** (партикли) та стандартні приклади TextMeshPro. Права на них належать їхнім авторам.
